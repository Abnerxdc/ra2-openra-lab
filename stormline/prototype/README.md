# Stormline 首批接入原型

此目录包含两个原创主战车辆的规则、武器、静态 PNG 和序列。它是固定 RA2 模组上的隔离叠加验证，不是完整独立游戏，也不是可发布安装包。

## 可重复验证

先编译固定的 OpenRA/ra2 和配套引擎，然后运行：

```powershell
./scripts/Test-StormlinePrototype.ps1 -ModDirectory '<固定模组目录>' -DotnetPath '<项目 SDK 的 dotnet.exe>'
```

脚本将上游模组复制到忽略目录内的全新暂存目录，增加本目录的资源与清单引用，运行已审查的 Utility YAML 检查。原始上游与 KK 文件不被修改。详细日志和暂存路径写入忽略的 `reports/`。每次生成独立目录，不自动清理旧目录。

脚本还编译纯 CPU 的精灵检查器，直接调用固定引擎 `PngSheetLoader`，验证两个 PNG 可解码、各含一个 1254×1254 RGBA 帧、存在可见与完全透明像素。该检查不创建渲染器、音频设备或游戏窗口。

本体资源只引用先前放入 `local/support/Content/ra2` 的隔离副本。当前叠加仍继承 RA2 基础规则、地图、界面与部分资源引用，不能作为无需原版资源的完整原创模组发布。保留上游许可证和署名；本目录不改变整个项目尚未选择许可证的状态。

## 接入范围

- `dc_prism`：700 HP、1000 资金、6 格射程、85 基础伤害，60 tick 装填。
- `cu_anvil`：1050 HP、1100 资金、5 格射程、100 基础伤害，75 tick 装填。
- 固定模组默认每 tick 40ms，因此装填分别为 2.4 秒与 3 秒；速度按 1024 世界单位/格、25 tick/秒换算为 94 与 66，近似设计目标 2.3 与 1.6 格/秒。地形与状态修正会影响实际速度。
- 自有武器不引用原版开火音效或命中特效；原型弹体不可见，尚未接入原创特效。
- 单位可供后续地图放置；暂不加入生产菜单或 AI 编队，避免未完成的方向动画进入正常遭遇战。

## 当前限制

本次实际执行结果：隔离叠加的 YAML 检查退出码 0，无 Error/Warning；精灵检查器 Release 构建 0 警告、0 错误；两张 PNG 均通过配套引擎解码，各一帧、1254×1254、Rgba32，透明与可见像素均存在。日志保持本地。首次挂载顺序与尺寸假设问题修正后已重跑通过。

两辆车都只有一个西南朝向，炮塔与车体合为一张图。转向时图片不会改变；没有玩家色遮罩、独立阴影、履带/车轮动画、受损或死亡动画。暂定 Scale=0.085，实际大小、锚点、遮挡和点击范围仍需画面验收；目前没有做这些测试。

YAML 检查验证规则与序列声明，PNG 检查验证 CPU 解码；两者均不证明实际显示、移动、攻击或完整对局正确。下一阶段先补齐一致的方向资源、独立炮塔和玩家色，再制作可控对战地图及生产接入。完整遭遇战、图形和声音验收仍需用户明确允许。

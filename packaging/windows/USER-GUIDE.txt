RA2 Lab Preview 0.1 — Windows x64

这是等待运行验收的预览构建，不是已完成验收的正式版。
安装器和游戏尚未在当前机器执行；画面、声音、完整遭遇战与卸载仍待验证。

安装（待用户允许后验证）：
1. 运行安装包，程序安装到当前用户的本地应用目录，不需要管理员权限。
2. 双击桌面的 RA2 Lab 快捷方式。
3. 首次选择自己有权使用的本机红警2资源目录，其中须有 ra2.mix 和 language.mix。
   theme.mix 为可选音乐。程序只复制，不修改源文件。
4. 资源准备后进入 OpenRA/ra2；选择单人遭遇战、地图、阵营和 AI。

安装包携带 .NET 6 运行时，不要求安装 SDK。
启动前置：现代 Windows x64、可用的图形驱动与系统 .NET Framework 4.x；
具体 Windows 版本、显卡、缩放、输入与声音兼容性未验收。

程序：本地应用目录 Programs\RA2Lab。
资源与设置：本地应用目录 RA2Lab\Support，与原游戏目录隔离。
卸载：Windows 应用列表或开始菜单的 RA2 Lab 卸载入口。
卸载仅删除本安装包拥有的文件，保留资源、设置与日志。

当前主入口使用固定 OpenRA/ra2 的本体遭遇战。
原创 Stormline 双阵营仍为独立开发原型，没有假装集成到完整对局。
OpenRA/ra2 与原版红警2在规则和表现上可能存在差异。

许可与来源：见 licenses 与 sources 目录。
OpenRA 和上游 RA2 模组的许可证、署名保持原样。
本项目自有代码的整体许可证尚未选定；本预览不代表授予通用再分发许可。
原版 MIX 资源不在安装包中；必须由用户自行提供。
第三方许可完整性与资源供应方案的发布审核尚未完成，不作为公开发布版本。

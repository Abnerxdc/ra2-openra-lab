# 本地资源接入

只用于用户自行持有的本机资源。不得把原版资源随公开仓库或安装包发布；安装包资源供应与分发方案尚未确定。当前工作没有完成法律许可核验。

先用 `scripts/Test-Upstream.ps1` 编译固定模组与配套引擎，再运行：

```powershell
./scripts/Test-MixResources.ps1 -ModDirectory '<模组目录>' -DotnetPath '<项目 SDK 的 dotnet.exe>' -ResourceFiles '<ra2.mix>', '<language.mix>'
./scripts/Stage-LocalContent.ps1 -SourceDirectory '<用户本机资源目录>'
```

检查工程位于忽略目录 `local/mix-validator`，只调用固定引擎 MIX 读取逻辑，不启动游戏、图形或音频。加密头解析依赖该引擎私有方法，不承诺兼容其他版本。检查包括顶层及已知包名对应嵌套 MIX 的索引范围、声明数据区范围和重复哈希；未知名称的嵌套包、校验和、真实性、载荷解码与完整资源引用尚未验证。

隔离复制位置为 `local/support/Content/ra2`。只处理本体必需的 `ra2.mix`、`language.mix` 以及源目录存在时的可选 `theme.mix`；不覆盖不同内容的目标文件，复制后核对 SHA-256。相同哈希仅证明复制一致。中断留下的不完整文件会导致下次运行拒绝覆盖，需人工检查。该入口不会启动上游图形资源导入器。

本次实际结果：两个本体顶层包和 20 个已知嵌套包检查通过；两个必需包隔离复制并核对哈希通过。未发现独立音乐包，因此本次没有复制音乐包，不能据此判断嵌套音乐或源游戏音乐是否缺失。详细结果仅写入忽略的 `reports/`。

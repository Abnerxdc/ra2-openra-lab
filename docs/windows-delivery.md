# Windows 交付路线与验收

当前交付候选：RA2 Lab 0.1.0 Preview，Windows x64，基于固定 OpenRA/ra2 本体遭遇战。它不是已完成运行验收的正式交付。Stormline 原创阵营仍是独立原型，不宣称已具备完整生产、AI 与对局。

## 构建

```powershell
./scripts/Build-WindowsPackage.ps1 -ModDirectory '<固定模组源码目录>' -DotnetPath '<项目 SDK 的 dotnet.exe>' -MakeNsisPath '<便携 NSIS 的 makensis.exe>'
./scripts/Test-ResourceBootstrap.ps1
```

使用 NSIS 3.11 便携 ZIP，仅解压编译器、不执行安装器。下载文件必须匹配官方 SHA-256：`c7d27f780ddb6cffb4730138cd1591e841f4b7edb155856901cdf5f214394fa1`。官方来源：[发布文件页](https://sourceforge.net/projects/nsis/files/NSIS%203/3.11/nsis-3.11.zip/download)。本机官方重定向曾返回 HTML，未通过校验；镜像 ZIP 只有在匹配上述官方摘要后才解压。

打包入口重新编译固定引擎、模组与 Windows 启动器，关闭调试记录并映射源码路径。随后创建全新的忽略暂存目录，复制运行依赖、模组数据、引擎着色器、运行时、许可证、署名与对应的原样上游源码归档。只携带 .NET 6.0.36 运行时，不携带 SDK。配套引擎版本不独立升级。

应用启动入口用系统 .NET Framework 4.x 编译为 Windows x64 程序。它只在用户主动打开快捷方式时显示首次资源选择界面；安装结束不自动启动游戏。现代 Windows 的具体版本与图形驱动兼容性仍待实机测试。

## 资源与本机数据

安装包不包含原版 MIX。首次由用户选择自己有权使用的本机资源目录，程序只读复制 `ra2.mix`、`language.mix` 与存在时的可选 `theme.mix`，校验 SHA-256，不修改源文件。不扫描或控制 KK 平台，不运行原版游戏 EXE。

资源复制到当前用户独立数据目录，完成标记不记录源目录。再次导入保留旧副本；中断留下的 pending 目录不自动覆盖现有内容。当前没有独立音乐包，挂载后的声明音轨均不存在，因此背景音乐尚不可用。这是明确缺口，不能以“音乐可选”算作音乐验收通过。

程序安装到当前用户目录，创建桌面与开始菜单快捷方式以及 Windows 卸载项。卸载代码按构建时生成的文件清单删除程序文件，仅尝试移除空目录，保留用户资源、设置与日志。以上描述的是已编写的行为；安装、快捷方式、升级与卸载实际运行仍未验证。

## 无界面门槛

`Test-WindowsPayload.ps1` 在编译 NSIS 前强制检查：没有 MIX、PDB、测试宿主和开发目录；没有当前工作区或用户目录的 UTF-8/UTF-16 绝对路径；必需模组 DLL 与依赖清单齐全；自带运行时可执行且不含 SDK；打包版本 Utility 的 YAML 和全部默认地形/精灵检查；模型、音频与字体文件头检查。

`Test-GameResourcePayloads.ps1` 使用固定引擎的 ModData/文件系统、VXL/HVA 读取器和 PCM 解码器，不创建 World、渲染器或 Sound 设备，不播放音频。范围包括默认模型序列、声明的具体语音/通知变体、武器开火音与两个字体文件头，不覆盖所有 Actor 特效音、地图自定义覆盖或字体实际渲染。

当前资源修补后实际结果：87 组 VXL/HVA、906 个音频文件解码成功，2 个字体头可读，范围内无失败。三个地形全部默认精灵/地块检查通过。资源导入测试使用合成数据，验证复制、哈希、源文件不变、可选音乐、失败保留和旧副本保留；不冒充游戏资源真实性测试。

新增检查器初版直接引用模组程序集，导致重复加载上下文与虚假的 Trait 类型不匹配。已改为通过模组自己的加载上下文获取读取器；未据此错误修改颜色预览规则。打包时亦补齐模组 `.deps.json`。本机音频引用问题以 [兼容修补](../patches/ra2/README.md) 记录。

## 仍需验收

- 安装器实际运行、快捷方式、首次资源准备界面、游戏启动与设置保存。
- 画面、输入、分辨率、缩放、切屏、声音输出，以及缺失背景音乐的资源供应。
- 两阵营从建造、采矿、供电、交战到 AI 与胜负判定的完整遭遇战；崩溃、卡死与行为差异排查。
- 卸载确实保留数据、重新安装与恢复，以及目标 Windows 环境兼容性。
- Stormline 完整方向资源、玩家色、生产、AI、原创地图及玩法闭环。
- 自有代码整体许可证、第三方许可完整性与公开分发审核。

用户此前禁止启动游戏、安装器、图形测试和声音。在用户明确允许前，不能执行上述交互检查，也不能宣布最终交付目标已达成。预览包只作为具体可审查的候选工件。

## 可重复构建

从官方 GitHub codeload 下载上述模组提交归档，并将指定引擎归档解压至模组的 `engine/`。SDK ZIP 解压至项目的 `.tools/dotnet/`。不要运行 launch-game、默认启动入口、安装器或打包程序。

```powershell
./scripts/Test-Upstream.ps1 -ModDirectory '<模组源码目录>' -DotnetPath '<项目内 dotnet.exe>'
```

脚本仅调用两次 dotnet build 和审查过的 Utility YAML 检查，日志保存在 reports。MIX 检查原型源码为 scripts/MixStructureCheck.cs；在本地临时 net6.0 控制台项目中引用配套引擎 OpenRA.Game.dll 和 OpenRA.Mods.Cnc.dll，传入待检查文件列表。其私有方法反射仅适用于固定引擎版本。

- 采矿、供电、建造、寻路、战斗及超武的行为和原版一致性均未知；尚未形成完整差异清单或工作量估算。

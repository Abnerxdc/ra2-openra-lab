# 固定上游兼容修补

不修改忽略目录中的原样上游。打包时复制此目录，再把 Voices/Weapons 清单项追加到对应列表末尾。

通过本机隔离资源的只读索引与 PCM 解码检查发现：步兵死亡定义把 `DisablePrefixes` 错放在 `Voices` 字典内；一处防空导弹开火音有拼写错误；少量语音候选在当前本体音频中不存在。修补移动元数据、修正明确拼写，并把工程师语音限制为双方都存在的变体，移除个别不存在的候选。

鳄鱼部分可选语音与基洛夫反馈没有对应音频，此预览将这些事件设为空，保留已存在的攻击、移动等其他音频。不用其他动物或其他单位音频冒充。尚未听音、未验证原版表现一致性；无界面解码不替代声音验收。不同语言/发行版资源仍需单独验证，不能据一个本机目录推断所有版本兼容。

规则引用来自固定 OpenRA/ra2；保留上游 GPL 许可证与署名。不包含原版声音、音频目录清单、哈希或源目录信息。
